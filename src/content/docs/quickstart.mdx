Kinglet is self-hosted and ships as one public image, so no registry login or
build is needed. Pick how you want to run it; each tab is the shortest path, and
its full page in [Deploy](/deploy/) covers TLS, upgrades, and troubleshooting.

## 1. Run Kinglet

<Tabs syncKey="deploy-method">
<TabItem label="Docker">

```bash
docker run -d --name kinglet \
  --restart unless-stopped \
  -p 127.0.0.1:8080:3000 \
  -v kinglet-data:/data \
  -e KINGLET_BASE_URL=http://localhost:8080 \
  ghcr.io/rushlightlab/kinglet:0.4.0
```

Open `http://localhost:8080`. Read the generated admin password with:

```bash
docker exec kinglet cat /data/admin-password.txt
```

Full guide: [Docker](/deploy/docker/).

</TabItem>
<TabItem label="Docker Compose">

Save as `docker-compose.yml`:

```yaml title="docker-compose.yml"
services:
  kinglet:
    image: ghcr.io/rushlightlab/kinglet:0.4.0
    restart: unless-stopped
    ports:
      - "127.0.0.1:8080:3000"
    environment:
      KINGLET_BASE_URL: http://localhost:8080
    volumes:
      - kinglet-data:/data

volumes:
  kinglet-data:
```

```bash
docker compose up -d
docker compose exec kinglet cat /data/admin-password.txt
```

Open `http://localhost:8080`. For HTTPS with Caddy, see
[Docker Compose](/deploy/docker-compose/#https-with-caddy).

</TabItem>
<TabItem label="Dokploy">

<Steps>

1. Create a **Docker Compose** service and paste the
   [Kinglet compose file](/deploy/dokploy/#2-paste-the-compose-file).

2. In **Environment**, set `KINGLET_BASE_URL=https://<your-domain>`.

3. In **Domains**, add your domain with container port `3000`, HTTPS on, and
   **Let's Encrypt**.

4. Click **Deploy** and open `https://<your-domain>`. The generated admin
   password is in the service logs.

</Steps>

Then set `KINGLET_TRUSTED_PROXIES` to Traefik's address as shown in
[Dokploy](/deploy/dokploy/#trusted-proxy).

</TabItem>
<TabItem label="Coolify">

<Steps>

1. Choose **+ New → Docker Image** and enter
   `ghcr.io/rushlightlab/kinglet:0.4.0`.

2. In **General**, set **Ports Exposes** to `3000`.

3. In **Persistent Storage**, add a **Volume Mount** with destination `/data`.

4. In **Environment Variables**, set `KINGLET_BASE_URL=https://<your-domain>`.

5. In **Domains**, add `https://<your-domain>:3000`.

6. Click **Deploy** and open `https://<your-domain>`. The generated admin
   password is in the application logs.

</Steps>

Then set `KINGLET_TRUSTED_PROXIES` to the proxy's address as shown in
[Coolify](/deploy/coolify/#trusted-proxy).

</TabItem>
<TabItem label="From source">

```bash
git clone https://github.com/rushlightlab/kinglet.git
cd kinglet
cp .env.example .env
docker compose up -d --build
docker compose exec kinglet cat /data/admin-password.txt
```

Open `http://localhost:8080`. For the development servers instead, see
[Build from source](/deploy/build-from-source/#development-servers).

</TabItem>
</Tabs>

## 2. Sign in

Sign in as `admin@kinglet.local` with the generated password, or with the
`KINGLET_ADMIN_EMAIL` / `KINGLET_ADMIN_PASSWORD` you set before the first boot.
Store the password somewhere safe and delete `/data/admin-password.txt`.

## 3. Send your first event

1. Open **Settings → Projects**.
2. Choose **manage** next to the project.
3. Create a key with **ingest** (and **query** if scripts should read logs).
4. Copy it now — it is shown once.

Set `KINGLET_URL` to the address you opened in step 1, then send an event:

```bash
export KINGLET_URL=http://localhost:8080   # or https://<your-domain>

curl -X POST "$KINGLET_URL/v1/events" \
  -H "Authorization: Bearer kl_…" \
  -H "Content-Type: application/x-ndjson" \
  --data-binary '{"level":"info","message":"hello from my app","service":"my-app"}'
```

The event appears in the live tail immediately. Clients for TypeScript, Python,
Go, PHP, curl, and Vector are in [HTTP ingestion](/ingestion/).

<Aside type="caution" title="Going to production">
  The Docker, Compose, and source tabs serve plain HTTP on port 8080. For a public instance, set
  `KINGLET_BASE_URL` to your HTTPS origin, put a TLS proxy in front, and read [Security](/security/)
  first.
</Aside>
