---
title: Quickstart
description: Kinglet up and running in five minutes.
---

import { Steps, Aside } from "@astrojs/starlight/components";

<Steps>

1. **Start the server**

   From a clone of this repository:

   ```bash
   docker compose up -d --build
   ```

   Kinglet is a single container backed by a volume — no Redis, no Kafka,
   no Postgres.

2. **Sign in as the administrator**

   The first boot (or a database with no administrator) creates one. If you
   didn't set `KINGLET_ADMIN_EMAIL` / `KINGLET_ADMIN_PASSWORD`, the generated
   password is in the container logs and, for the default local database, in
   `admin-password.txt`:

   ```bash
   docker compose exec kinglet cat /data/admin-password.txt
   ```

3. **Open the UI and sign in**

   Visit `http://localhost:8080` and sign in with the admin email (default
   `admin@kinglet.local`) and that password. Hit **spray demo** to watch
   the live tail, histogram, and filter bar do their thing.

4. **Create an API key and send a real event**

   In **/settings → projects & keys**, create a key with the `ingest` scope,
   then:

   ```bash
   curl -X POST http://localhost:8080/v1/events \
     -H "Authorization: Bearer kl_…" \
     -H "Content-Type: application/x-ndjson" \
     --data-binary '{"level":"info","message":"hello from my app","service":"my-app"}'
   ```

   It appears instantly — the UI subscribes over SSE while it's live.

</Steps>

<Aside type="tip" title="No Docker yet?">
  Kinglet runs from source too: clone the repo, then
  `pnpm install && pnpm dev`. The API listens on `:3000`, the UI on `:5173`
  and proxies to it.
</Aside>
